Experiment 4

Exhaustive Feature Selection & Ensembling Complete

To rigorously test the impact of SPEAR embeddings, GLCM Textures, and Terrain features against a Sentinel-2 baseline, we built an exhaustive cross-validation pipeline. The pipeline dynamically removes correlated features (r > 0.90), runs Permutation Importance to select the Top-K features, and trains three gradient boosters (LightGBM, XGBoost, CatBoost) plus a Stacking Meta-Learner.

Feature Set Initial -> Selected Winning Config (CV) Best Single Model F1 Simple Ensemble F1 Stacking F1
1. S2 Only 11 -> 6 (Top 6) 5 Folds / LightGBM 0.4834 0.4831 0.4695

3. S2 + SPEAR + Terrain + GLCM 61 -> 27 (Top 15) 5 Folds / XGBoost 0.5711 0.5746 0.5564
Breakthrough Discovery: In lightweight tests, adding Terrain and GLCM caused the model to overfit severely (F1 dropped to ~0.41). However, when passed through the rigorous Permutation Importance filter, we identified the Absolute Top 15 features out of 61. By stripping away the noise, XGBoost successfully synergized the non-linear SPEAR embeddings with Terrain/GLCM to achieve a massive performance leap to 0.5746 Macro F1.

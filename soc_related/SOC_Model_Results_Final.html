Soil Organic Carbon Estimation from Satellite Data
Sentinel-2 and AlphaEarth Embeddings — Model Results
Study area: Doaba region, Punjab  |  40 field plots  |  Imagery: October 2025  | 

1. Study Overview

This report presents the results of two complementary modelling efforts to predict Soil Organic Carbon (SOC) concentration from satellite imagery. The central question is whether freely available satellite data — Sentinel-2 multispectral bands and foundation model embeddings derived from them — can reliably estimate field-measured SOC without laboratory analysis.

A baseline plot-level approach was first developed using established soil spectroscopy methods. This was subsequently extended by incorporating bare soil detection and a pixel-level modelling strategy to assess whether additional information can improve predictive accuracy.

2. Data

Field plots
40 agricultural plots in the Doaba region, Punjab. Laboratory SOC measurements were collected in October 2025. SOC concentration ranges from 0.13% to 1.01%, with a mean of 0.54%.
Satellite imagery
Sentinel-2 Surface Reflectance (10 m resolution), October 2025 monthly median composite. Exported from Google Earth Engine as per-pixel tables covering each plot boundary.
Spectral bands
12 bands: B1, B2, B3, B4, B5, B6, B7, B8, B8A, B9, B11, B12.
AlphaEarth embeddings
64-dimensional per-pixel embeddings (A00 to A63) generated by Google's AlphaEarth geospatial foundation model, derived from the same Sentinel-2 imagery.
Bare soil detection
A separately trained XGBoost classifier assigns a binary bare or non-bare label to each pixel. Across all 40 plots, 19.2% of pixels are classified as bare soil. Used as an additional feature in the extended pixel-level analysis (Section 5).
Pixel count
1,619 pixels across 40 plots (4 to 112 pixels per plot).

3. Plot-Level Models

Both models below treat each plot as a single observation. Pixel-level data is aggregated into one feature vector per plot before training. The target variable is the single laboratory SOC measurement for that plot.

Pixel aggregation and outlier removal

Raw per-pixel band values are filtered before aggregation. Pixels falling in the furthest 15% from the plot's spectral centre, as measured by Mahalanobis distance, are discarded. This removes cloud edges, shadow pixels, and other spatial outliers without requiring a cloud mask. The remaining pixels are averaged to produce a single feature vector per plot. For AlphaEarth embeddings, the same Mahalanobis mask computed on the spectral bands is applied to the 64-dimensional embedding vectors before averaging.

Model 1 — Sentinel-2 spectral bands

Input: 12 spectral band averages per plot (after Mahalanobis filtering).
Model: Partial Least Squares Regression (PLSR). The number of latent components is tuned by cross-validation inside the 39 training plots at each LOO fold.
Output: Predicted SOC percentage.

Model 2 — AlphaEarth embeddings

Input: 64-dimensional AlphaEarth embedding vector per plot (after Mahalanobis filtering and averaging).
Model: ElasticNet regression. The L1 penalty induced automatic feature selection, retaining 6 of the 64 embedding dimensions.
Output: Predicted SOC percentage.

Validation

Both models are validated by strict Leave-One-Out Cross-Validation (LOO-CV) across all 40 plots. In each fold, all model settings — number of PLSR components or ElasticNet regularisation strength — are tuned by cross-validation on the 39 training plots. The held-out plot has no influence on any decision. This gives 40 independent out-of-sample predictions, one per plot.

The accuracy column in the table below reports the fraction of plots for which the absolute prediction error is below a defined agronomic tolerance threshold. The baseline corresponds to predicting the regional mean SOC (0.54%) for every plot.

5. Extended Analysis — Pixel-Level Approach

As a supplementary investigation, a pixel-level modelling strategy was evaluated to determine whether retaining individual pixel observations rather than collapsing to plot summaries improves predictive performance.

Approach

All 1,619 pixels from all 40 plots are used as individual training samples. Each pixel inherits the laboratory SOC measurement of its parent plot as its label. To prevent data leakage, validation remains plot-level: in each LOO fold, all pixels belonging to the held-out plot are excluded from training. The model generates per-pixel SOC predictions for the held-out plot, and the mean of those predictions is taken as the plot-level SOC estimate. This yields 40 independent plot-level predictions, directly comparable to the results above.

Four feature combinations were evaluated, each incorporating progressively richer inputs:

  • A — 12 Sentinel-2 spectral bands
  • B — S2 bands + 64 AlphaEarth embedding dimensions (76 features)
  • C — S2 bands + 5 derived spectral indices (BSI, NDVI, NDWI, SWIR ratio, brightness) + AEE (81 features)
  • D — All of the above + per-pixel bare soil prediction (82 features)

Three model types were assessed per feature set: PLSR (for direct comparison), Ridge Regression, and XGBoost (gradient-boosted trees). XGBoost with inner hyperparameter tuning was the strongest performer.

The pixel-level XGBoost model (feature set D) achieves R2 = 0.143 with RMSE = 0.181%. This is comparable in accuracy to Model 1 from the plot-level analysis (R2 = 0.154, RMSE = 0.179%), but is reached by a different route: retaining spatial heterogeneity within plots rather than summarising it. The two approaches are therefore complementary. PLSR and Ridge perform markedly worse when applied at the pixel level with high-dimensional AEE features, confirming that non-linear methods are better suited to exploiting the embedding dimensions.

6. Summary and Discussion

Approach Model R2 RMSE MAE
Plot-level (Mahalanobis filter + mean) PLSR on S2 bands 0.154 0.179% 0.146%
Plot-level (Mahalanobis filter + mean) ElasticNet on AEE 0.090 0.186% 0.141%
Pixel-level (all pixels, plot-level LOO) XGBoost on S2 + Indices + AEE + Bare 0.143 0.181% 0.143%
Baseline — regional mean prediction 0.000 0.200% 0.151%

All three modelling approaches outperform the regional mean baseline. The PLSR model on Sentinel-2 bands achieves the highest R2, consistent with the long-established utility of visible and shortwave infrared reflectance as proxies for soil organic matter. The AlphaEarth embedding model achieves the lowest average per-plot error (MAE), suggesting that foundation model representations compress information in a way that is particularly effective at reducing large individual prediction errors.

The primary constraint across all approaches is the size of the labelled dataset. With 40 plots and one SOC measurement per plot, any LOO fold trains on 39 unique labels. Soil spectroscopy literature consistently reports that reliable PLSR-class models require a minimum of 80 to 150 calibration samples. The results here are therefore best interpreted as demonstrating directional feasibility rather than operational reliability. Expanding the ground-truth dataset to 80 or more plots remains the highest-priority action for improving all three model types.

A secondary opportunity lies in restricting model training and inference to pixels where the soil surface is confirmed to be exposed (bare soil fraction currently 19.2% across plots). When vegetation covers the soil, Sentinel-2 reflectance primarily encodes canopy properties, not soil chemistry, adding noise to the regression. Stratifying by bare soil classification before modelling is expected to improve the signal-to-noise ratio, particularly for mixed plots.

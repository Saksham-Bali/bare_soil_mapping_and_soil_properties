Soil Organic Carbon (SOC) Estimation — Model Results Report
Project: Bare Soil Mapping and SOC Estimation  |  Data: Sentinel-2 October 2025, 40 Field Plots  | 

1. Objective

This report documents the results of training and evaluating machine learning models for predicting Soil Organic Carbon (SOC) percentage from Sentinel-2 multispectral imagery. The core research question is whether adding Alpha Earth Embeddings (AEE) and a bare soil detection signal to standard spectral band features improves SOC prediction accuracy.

Two modelling approaches were evaluated: a plot-level approach that reduces each field plot to a single feature vector (following the baseline method), and a pixel-level approach that treats each individual pixel as a training sample while preserving plot-level validation integrity.

2. Data Description

Field plots
40 agricultural plots. Each plot has one ground-truth SOC measurement (SOC_pct), ranging from 0.13% to 1.01%.
Imagery
Sentinel-2 (10 m resolution), October 2025 monthly median composite. Exported via Google Earth Engine as pixel-level CSV tables.
Spectral bands (S2)
12 bands: B1, B2, B3, B4, B5, B6, B7, B8, B8A, B9, B11, B12.
Spectral indices (derived)
5 indices computed from S2 bands: BSI (Bare Soil Index), NDVI, NDWI, SWIR Ratio, and Brightness.
Alpha Earth Embeddings (AEE)
64-dimensional per-pixel embeddings (A00 to A63) generated by the Alpha Earth foundation model. These are pixel-level features with small spatial variation within each plot.
Bare soil prediction
Per-pixel binary label (0 = not bare, 1 = bare soil) from a separately trained XGBoost bare-soil classifier. Overall bare fraction across all plots: 19.2%.
Total pixels
1,619 pixels across 40 plots (4 to 112 pixels per plot, median approximately 40).

4. Modelling Approaches

4.1 Plot-Level Approach (Baseline)

Each plot is reduced to a single row by computing the spatial median of all pixel values across each feature dimension. This yields a dataset of 40 rows (one per plot) with one SOC label per row. A Partial Least Squares Regression (PLSR) pipeline (StandardScaler + PLSRegression) is trained, with the number of latent components tuned by grid search over {1, 2, 3, 4, 5, 6, 8, 10}.

Validation uses strict Leave-One-Out Cross-Validation (LOO-CV) across all 40 plots. This mirrors the approach used in the team's baseline model (model_minimal.py).

4.2 Pixel-Level Approach

All 1,619 pixels from all 40 plots are used as individual training samples. Each pixel inherits the SOC label of its parent plot. To prevent data leakage, validation is still conducted at the plot level: in each LOO fold, all pixels belonging to the held-out plot are withheld from training. The model is then used to predict SOC for each withheld pixel, and the mean of those pixel predictions constitutes the plot-level SOC estimate.

Three model types are evaluated: PLSR (for direct comparison with the baseline), Ridge Regression (linear, regularised), and XGBoost (gradient-boosted trees, non-linear). Inner hyperparameter tuning uses 5-fold cross-validation on the training plots.

6. Interpretation

6.1 Pixel-level training outperforms plot-level

The shift from 40 plot-level rows to 1,619 pixel-level rows moves all best-case results from negative to positive R-squared territory. Even though every pixel within a plot carries the same SOC label (the ground-truth measurement), the spatial variation in spectral and embedding features within a plot provides additional signal that the model can learn from. This confirms that the spatial median reduction in the plot-level approach discards useful intra-plot variability.

6.2 AEE features only help with non-linear models

Adding AEE embeddings to S2 bands harms PLSR and Ridge performance substantially (R2 drops from approximately -0.05 to -0.55 for PLSR at pixel level). With 76 to 82 features and only ~1,580 training pixels spanning just 39 unique SOC labels, linear methods cannot identify a meaningful regression direction through the high-dimensional feature space without overfitting. XGBoost, which builds shallow trees and regularises implicitly through subsampling, is able to exploit the AEE dimensions productively, improving R2 from +0.056 (S2 only, Ridge) to +0.143 (full feature set, XGB).

6.3 Bare soil prediction contributes marginally

The difference between Variant C and Variant D under XGBoost is R2 = 0.001 (0.142 vs 0.143). The bare soil signal adds almost no independent information at this scale because it is already partially captured by NDVI and the Bare Soil Index included in the spectral indices block. The bare soil classifier may provide more discriminative power if SOC is modelled separately for bare and vegetated pixels, rather than as a single unified model.

6.4 The overall R-squared remains low

An LOO R-squared of +0.143 means the best model explains approximately 14% of the variance in plot-level SOC. This is the primary result to communicate to stakeholders: the model is directionally correct but not yet reliable enough for operational use. The constraint is not the modelling method but the number of unique ground-truth SOC measurements. With only 40 labelled plots, even the best model has limited ability to generalise.

The LOO predictions are computed from pixels trained on the remaining 39 plots, so there is no data leakage between the held-out plot and the training set. However, the 40-plot dataset is small enough that single outlier plots can move aggregate metrics by several percentage points. Metrics should be interpreted with this uncertainty in mind.

8. Next Steps

Priority 1 — Expand the ground-truth dataset

This is the single highest-leverage action. Doubling the number of labelled plots from 40 to 80 would be expected to substantially improve LOO R-squared. Literature on soil spectroscopy with Sentinel-2 typically requires a minimum of 80 to 150 calibration samples before PLSR-class models become reliable. Collecting SOC measurements for additional plots in the study area, or integrating publicly available soil survey data (e.g. from ICAR, NBSS&LUP, or the ISRIC World Soil Database), should be the immediate focus.

Priority 2 — Stratify bare and non-bare pixels

SOC measured from Sentinel-2 is only physically meaningful when the soil surface is exposed. Pixels classified as vegetated (bare_pred = 0) are contributing noise to the regression because the reflectance signal is dominated by vegetation, not soil. Training separate models for bare pixels (bare_pred = 1) and applying the model only to bare pixels during inference is expected to improve signal quality noticeably, particularly for plots with mixed bare and vegetated cover.

Priority 3 — Temporal stack instead of single-month composite

The current dataset uses only the October 2025 monthly median. The old dataset contains 12 monthly composites per plot. Stacking multiple months as additional features (e.g. using bands from March, October, and December, which correspond to dry, post-harvest, and post-Rabi sowing periods respectively) could expose seasonal SOC-reflectance patterns that a single-month snapshot misses. The existing s2_old parquet files already contain this temporal data for all 40 plots.

Priority 4 — Hyperparameter tuning with a larger search space

The current XGBoost grid search covers a modest parameter space to keep runtime manageable on 40 LOO folds. Once the dataset is larger, a broader search (including min_child_weight, gamma, and reg_lambda) or a Bayesian optimisation approach would be appropriate.

Priority 5 — Confidence intervals and uncertainty quantification

Operational SOC maps should report prediction uncertainty alongside point estimates. This can be achieved using XGBoost quantile regression or by training an ensemble of models with bootstrapped training sets. Uncertainty is especially important for plots with few valid pixels (some plots have as few as 4 pixels), where the spatial median or mean is statistically unreliable.
